# 海外短视频 / TikTok 脚本 SOP

写脚本前，按顺序执行。

## 1. 先读知识库
- 卖点：`brand-knowledge/product-selling-points.md`
- 人群：`brand-knowledge/target-audience.md`
- 调性：`brand-knowledge/brand-profile.md`

## 2. 结构（每条 15–30 秒）
- HOOK（0–3s）：一句反常识 / 价格 / 痛点，前 3 秒决定完播
- 痛点/场景（3–10s）：真实使用场景，让用户对号入座
- 演示（10–20s）：实测 + 具体数字，不空口说参数
- CTA（最后 3s）：评论区 / 链接，一句话

## 3. 每条脚本必须包含
- 口播词（说出来的话，口语、短句）
- 屏上文字（大字幕，≤ 8 字/行，突出数字和价格）

## 4. 去AI化
- 复用 brand-copy 的中英文禁用词表，口播词不得出现 AI 味词
- 给具体数字和场景，禁止「极致 / 震撼 / 颠覆」这类词

## 5. 批量生产
- 一个产品可拆 N 个脚本角度（价格 / 续航 / 复购 / 缺点诚实说 / 对比）
- 每个角度一个脚本，输出到 `content_output/tiktok_script/`
- 先出草稿，标注哪些值得拍

## 6. 输出格式
每条脚本按：HOOK / 场景 / 演示 / CTA 四段，每段写「口播词 + 屏上文字」。
末尾加「脚本自查」：钩子是否 3 秒内、是否有具体数字、是否有 CTA。
