# SEO & GEO 本地化内容 SOP

写 SEO/GEO 内容前，按顺序执行。

## 1. 先读知识库
- 关键词：`brand-knowledge/seo-keyword-bank.csv`（keyword / intent / funnel / volume / difficulty / region）
- 本地化参数：`brand-knowledge/geo-region-list.md`
- 品牌/卖点：`brand-knowledge/brand-profile.md`、`product-selling-points.md`

## 2. 关键词意图 → 内容类型
- 导航型（搜品牌名）→ 品牌词页、官网首页
- 信息型（"how / why / what / best"）→ 博客、攻略、对比文（TOFU / MOFU）
- 交易型（"buy / best / price"）→ 产品页、落地页（BOFU）

## 3. SEO 内容结构（站内）
- Title ≤ 60 字符，含主关键词
- Meta description ≤ 155 字符，含卖点 + CTA
- H1 一个，H2 分点，段落短
- 内链指向相关产品页 / 文章
- 结构化数据（Schema）：Product / FAQ / Review

## 4. GEO 优化（让 AI 搜索引擎引用你）
- 内容用「定义 / 列表 / 对比 / FAQ」结构——AI 爱引用这几种
- 每个核心问题先给一句直接答案，再展开
- 引用权威第三方来源（数据、报告）
- 把品牌名、产品名、参数写成清晰的「实体」，避免含糊
- 在权威第三方站点（Reddit / 评测站 / 媒体）有你的内容，增加被引用概率

## 5. 多地区本地化
- 按 `geo-region-list.md` 换语言 / 货币 / 单位
- 关键词不直译，用当地真实搜索词
- 用当地真实达人 / KOL / 案例

## 6. 输出格式
- SEO 文章：Title + Meta + H1 + 正文（H2 分点）+ FAQ + Schema 建议
- 落地页：Title + Meta + 首屏卖点 + 3 段 + 3 要点 + CTA
- 末尾加「GEO/SEO 自查」：关键词是否命中、结构是否可被 AI 引用、是否本地化

## 7. 质量线
- 关键词自然出现，不堆砌
- 每篇先给「一句话直接答案」，再展开（GEO 关键）
- 不瞎编数据，缺参数用【】占位
