# 内容复盘 & 资产沉淀 SOP

复盘前，按顺序执行。

## 1. 先读数据
- `brand-knowledge/content-performance.csv`（impressions / clicks / conversions / ctr）

## 2. 核心指标
- 曝光 impressions：触达多少
- 点击 / CTR：标题、钩子是否抓人
- 转化 conversions：内容是否推动下单
- 爆款标准：CTR 或转化率明显高于均值的内容

## 3. 复盘流程（四步）
1. 数据：按渠道 / 类型拉出表现排序
2. 归因：为什么爆 / 为什么扑（钩子？话题？平台？时间？）
3. 结论：提炼 1–3 条可复用的规律
4. 动作：下次内容怎么改、选题怎么调

## 4. 资产沉淀
- 爆款拆解：把爆款的钩子、结构、关键词拆成模板
- 更新提示词库和 SOP：把规律写回 SKILL.md 或 prompts/
- 输出到 `content_output/retrospective_assets/`

## 5. 输出格式
- 复盘报告：数据表 + 爆款 Top3 拆解 + 扑街 Bottom3 归因 + 下一步动作
- 末尾加「复盘结论」：一句话说清「下次做什么、不做什么」
