# 目标用户（Apple · 示例）

## 核心画像
- 年龄：18–40 岁
- 身份：学生党 / 年轻职场人 / 视频与创意创作者 / 已入生态用户
- 预算：能接受高价位，但看重「值不值」「能不能用很多年」
- 决策方式：看测评与实测数据，看重长期使用成本和保值率，对「参数内卷」话术反感

## 使用场景（痛点）
- 学生党：一天在外没插座、跨设备协作（iPhone 拍 → Mac 剪 → AirDrop 传）
- 年轻职场人：通勤路上刷视频 / 开会，看重续航与生态无缝
- 创作者：手机拍 4K 视频、Mac 剪辑、耳机监听，需要设备间顺滑衔接

## 他们讨厌什么
- 夸大宣传、AI 味文案、没有真实数据的空话
- 安卓阵营的「参数内卷」（跑分 / 充电瓦数 / 像素堆砌）
- 为短期参数牺牲长期使用体验

## 他们信什么
- 真实用户长期使用口碑（Reddit、YouTube 长测）
- 能查到的具体参数、实测续航、二手残值数据
